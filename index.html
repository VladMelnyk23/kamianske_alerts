Налаштування Microsoft Edge для постійної роботи
  1. Сон вкладок: edge://settings/system → вимкніть «Заощаджуйте ресурси за допомогою вкладок у режимі сну» або додайте цей сайт у виключення.
  2. Автозвук: edge://settings/content/mediaAutoplay → «Дозволити» для цього сайту.
  3. Сповіщення: значок замка в адресному рядку → Сповіщення → Дозволити.
  4. Режим ефективності: вимкніть для ПК на живленні й не давайте Windows засинати.
  5. Найстабільніше: Edge → «Програми» → «Установити цей сайт як програму». На вкладці з'явиться значок 🔊 — так і має бути.
  6. iPhone: Поділитись → «На початковий екран».
