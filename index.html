Налаштування Microsoft Edge для постійної роботи
  1. Сон вкладок: edge://settings/system → «Заощаджуйте ресурси за допомогою вкладок у режимі сну» → вимкніть, або додайте цей сайт у «Ніколи не переводити ці сайти в режим сну».
  2. Автозвук: edge://settings/content/mediaAutoplay → «Дозволити» для цього сайту (тоді звук відновлюється сам після перезавантаження).
  3. Сповіщення: значок замка в адресному рядку → Сповіщення → Дозволити.
  4. Режим ефективності: вимкніть для цього ноутбука/ПК на живленні, а в Windows не давайте йому засинати.
  5. Найстабільніше: Edge → «Програми» → «Установити цей сайт як програму» і працювати у вікні застосунку. На вкладці з'явиться значок 🔊 — так і має бути.
Натисніть «Увімкнути звук» один раз: це вмикає звук сирени й режим фонової роботи (сторінка тихо тримає аудіосесію, щоб браузер її не призупиняв). Можна згорнути браузер, але не закривайте вкладку. На iPhone надійніше додати сторінку на екран «Додому» (Поділитись → На початковий екран).
